# Roadmap

Lives in GitHub issues; this file says how they are chosen.

- **Now: First light** (milestone 1): Percolate watches a real repository live and
  is worth leaving on screen. Ends with v0.1.0.
- **Order of work:** a broken main first, then bugs people report, then replies to
  people, then the next issue labelled `ready` (lowest number first).
- **Labels:** `ready` (prerequisites met), `model:balanced` / `model:strong` (how hard),
  `bug`, `from-people`. Dependencies are GitHub "blocked by" links.
- **After First light:** brew0x decides, from what people ask for and what he sees
  when he watches real repositories.
